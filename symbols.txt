; SymbolKey 변환표
;  - 한 줄에 "이름=기호". 이름은 완성형 한글 음절만 (숫자·영문·자모 단독 불가)
;  - ";" 또는 "#"으로 시작하는 줄은 주석
;  - 수정 후 트레이 메뉴 "다시 불러오기"
;  - 이름 앞에 다른 글자가 붙으면("뮤지컬") 변환되지 않고, 숫자는 허용("2뮤" → "2μ")
;  - 이름 앞에 "?"를 붙이면("?각=∠") 일상어와 겹치는 이름으로 보고 수식 문맥에서만 변환한다:
;      "각 항목" → 그대로,  "2각" "sin(각" "= 각" "각)" "각/2" → ∠
;  - "따라서", "이상"처럼 평소 문장에 자주 쓰는 단어는 넣지 않거나 "?"를 붙이는 게 안전하다
;  - 변환 직후 백스페이스를 누르면 원래 친 글자로 되돌아간다
